# SKYNET_FLY — релізи SkynetFly (програма пілота для Windows для наземної станції SKYNET від DROZD TEAM)

Кожен реліз (`Releases`, тег `vX.Y.Z`) містить:

| файл | що це |
|---|---|
| `SkynetFly-<версія>.zip` | повна збірка: `SkynetFly.exe` і все потрібне поруч (Nuitka standalone) |
| `SkynetFly-<версія>.zip.sha256` | контрольна сума архіву |

## Встановлення

1. Завантаж `SkynetFly-<версія>.zip` з останнього релізу і розпакуй у будь-яку папку (не в `Program Files`).
2. Один раз запусти `install.bat` від адміністратора — додає виняток у Defender і відкриває порти у фаєрволі.
3. Запускай `SkynetFly.exe`.

## Оновлення

У програмі: **Налаштування → Оновлення програми → «Перевірити» → «Оновити»**.
Програма сама завантажить реліз, перевірить контрольну суму, закриється, замінить файли і запуститься знову.
`config.ini`, список станцій, записи (`rec`) і ключі (`keys`) зберігаються.

Програма також перевіряє наявність нової версії при запуску.
